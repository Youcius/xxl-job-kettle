# Triage labels

工程技能使用五类标准分拣角色。此文件把这些角色映射到本仓库 issue tracker 中实际使用的标签字符串。

| skill 中的标准角色 | 本仓库使用的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估 |
| `needs-info` | `needs-info` | 等待提问者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，适合交给 AFK agent 处理 |
| `ready-for-human` | `ready-for-human` | 需要人类实现或判断 |
| `wontfix` | `wontfix` | 不会处理 |

当某个 skill 提到某类分拣角色，例如“apply the AFK-ready triage label”，使用上表中对应的标签字符串。

如果以后 GitHub Issues 中实际标签改名，只需要修改此文件右侧“本仓库使用的标签”一列。
